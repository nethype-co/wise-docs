## What is the Text block?

<SectionMeta version="v1.0.0" availability="Theme block" />

The **Text** block adds body text to a section: a description, a few paragraphs, a list or a link. It is the most common block in the theme and appears in most section presets.

## Where can I use it?

Text is a theme block, so you can add it to any section or block that shows **Add block** in the theme editor, for example:

* [Image with text](/sections/storytelling/image-with-text), inside the **Image with text container**
* [Rich text](/sections/text/rich-text), [Collapsible menu](/sections/text/collapsible-menu) rows and [Content with navigation](/sections/text/side-nav-content)
* [Image banner](/sections/banners/image-banner) and [Slideshow](/sections/banners/slideshow) content
* The [product page](/product-page/product-information), the cart and the [footer](/header-footer/footer)

See [How sections and blocks work](/getting-started/sections-and-blocks) for how to add a block.

## Settings

* **Text:** The content. You can use the text editor to make words bold or italic, add links and create lists.
* **Text alignment (desktop)** and **Text alignment (mobile):** Align the text (options: Left, Center, Right, Inherit). **Inherit** follows the alignment of the section or block the text sits in.
* **Text scale (desktop)** and **Text scale (mobile):** Make the text smaller or larger (50 to 300%). 100% is the body text size set in your theme settings.

#### Colors

* **Text color:** Give this block its own text color. Leave it empty to use the color of the section.

#### Block spacing

* **Distance top (desktop):** Space above the block (0 to 60 px).
* **Distance bottom (desktop):** Space below the block (0 to 60 px).
* **Show custom mobile spacing:** Enable this setting to use different spacing on mobile. When it is on, **Distance top (mobile)** and **Distance bottom (mobile)** appear.

:::tip
To hide a Text block, clear the **Text** field. An empty Text block shows nothing.
:::

## Changing how text looks

The body font and its base size are set once for the whole store in **[Theme settings: Typography](/theme-settings/typography)**. Link colors are set in **[Theme settings: Colors](/theme-settings/colors)**.
