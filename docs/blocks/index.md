# Blocks

Wise is built from blocks. The blocks on this page are **theme blocks**: they are shared by the whole theme, so you can add them to any section that shows the **Add block** button and they work the same way everywhere. Each section article only lists the blocks that are specific to that section and links back here for the shared ones.
