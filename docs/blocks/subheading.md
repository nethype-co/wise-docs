## What is the Subheading block?

<SectionMeta version="v1.0.0" availability="Theme block" />

The **Subheading** block adds a short line of text in the subheading style, usually placed above a heading as a small label, for example *New collection* or *Tell your story*. It uses the subheading font from your theme settings, so it looks the same everywhere.

## Where can I use it?

Subheading is a theme block, so you can add it to any section or block that shows **Add block** in the theme editor, for example:

* The **Header** block at the top of most sections
* [Image with text](/sections/storytelling/image-with-text), inside the **Image with text container**
* [Rich text](/sections/text/rich-text) and [Countdown timer](/sections/text/countdown-timer)
* [Image banner](/sections/banners/image-banner) and [Slideshow](/sections/banners/slideshow) content
* Grid view items and collapsible rows

See [How sections and blocks work](/getting-started/sections-and-blocks) for how to add a block.

## Settings

* **Subheading:** The text of the subheading. You can make words bold or italic, add a link, or choose a heading level in the text editor. The level does not change the look: the text always uses the subheading style.
* **Text scale (desktop):** Make the subheading smaller or larger on desktop (50 to 300%). 100% is based on the body text size set in your theme settings.
* **Text scale (mobile):** Make the subheading smaller or larger on mobile (50 to 300%).

:::tip
To hide a subheading, clear the **Subheading** field. An empty Subheading block shows nothing.
:::

## Changing how subheadings look

The font, line height, letter spacing and capitalization of subheadings are set once for the whole store in **[Theme settings: Typography](/theme-settings/typography)**. The color follows the section's text color.
