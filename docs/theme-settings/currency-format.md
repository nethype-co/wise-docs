## Currency format

<SectionMeta version="v1.0.0" />

The **Currency format** setting decides whether prices show a currency code, for example *$10.00 USD* instead of *$10.00*. You'll find it under **Theme settings** > **Currency format** in the theme editor. To open theme settings, click the gear (settings) icon in the left sidebar of the theme editor.

## Settings

#### Currency codes

* **Show currency codes:** Add the currency code to prices on product pages, product cards, search results and other places in your store, for example *$10.00 USD*. When it is off, prices show only the currency symbol, for example *$10.00*.

Cart and checkout prices always show currency codes, whatever you choose here.

:::tip
Turn currency codes on when you sell in several currencies that use the same symbol, for example US, Canadian and Australian dollars. The code makes it clear which currency the customer pays in.
:::

The exact look of prices, such as the symbol and the decimal separator, comes from the currency formatting in your Shopify admin, under **Settings** > **General**, in the store currency section.
