## Social media

<SectionMeta version="v1.0.0" />

The **Social media** settings store the links to your social media profiles. You enter them once here, and every place in the theme that shows social icons uses them, for example the footer and the password page. You'll find these settings under **Theme settings** > **Social media** in the theme editor. To open theme settings, click the gear (settings) icon in the left sidebar of the theme editor.

## Settings

#### Social accounts

Paste the full address of each profile, starting with *https://*. Leave a field empty to hide that network.

* **X:** For example *https://x.com/shopify*.
* **Facebook:** For example *https://facebook.com/shopify*.
* **Pinterest:** For example *https://pinterest.com/shopify*.
* **Instagram:** For example *https://instagram.com/shopify*.
* **TikTok:** For example *https://tiktok.com/@shopify*.
* **Tumblr:** For example *https://shopify.tumblr.com*.
* **Snapchat:** For example *https://www.snapchat.com/add/shopify*.
* **YouTube:** For example *https://www.youtube.com/shopify*.
* **Vimeo:** For example *https://vimeo.com/shopify*.

The icons always appear in the same order: Facebook, Instagram, X, YouTube, TikTok, Pinterest, Snapchat, Tumblr, Vimeo.

## Where the icons appear

To show the icons, add a **Social icons** block where you want them, for example in the [Footer](/header-footer/footer). The [Password page footer](/pages/password-footer) shows them automatically.

Your profile links are also added to your store's [structured data](/theme-settings/structured-data), which helps search engines connect your social profiles to your store.
