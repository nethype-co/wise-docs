## What is the Password footer section?

<SectionMeta version="v1.0.0" />

The **Password footer** section is the bottom part of your password page. It shows your social media icons, an **Enter using password** link that opens the password form, a link for the store owner to log in, and the "Powered by Shopify" note.

## Where to find it

In the theme editor, open the page selector at the top of the screen and choose **Password** (in some stores it is listed under **Others**). The Password footer appears in the sidebar below the [Password](/pages/password) section.

The section is part of the password page layout, so you cannot remove or move it. This makes sure visitors always have a way to enter the store with the password.

## What it shows

The content of the footer is filled in automatically:

* **Social media icons:** The links you entered in [Theme settings > Social media](/theme-settings/social-media). Networks without a link are not shown, and when no link is set the icons are hidden.
* **Enter using password:** Opens a popup where visitors type the store password.
* **Store owner link:** Lets you log in to your Shopify admin.
* **Powered by Shopify.**

## Section settings

* **Show line:** Show a thin line at the top of the footer, to separate it from the content above.

#### Colors

* **Background color:** Set the background color of the section.
* **Background gradient:** Set a background gradient. A gradient overrides the background color.
* **Text color:** Set the text color for the whole section.

#### Section spacing

* **Distance top (desktop):** Space above the section on desktop (0 to 100 px).
* **Distance bottom (desktop):** Space below the section on desktop (0 to 100 px).
* **Show custom mobile spacing:** Enable this setting to use different spacing on mobile. When it is on, **Distance top (mobile)** and **Distance bottom (mobile)** appear.
