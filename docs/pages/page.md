## What is the Page section?

<SectionMeta version="v1.0.0" />

The **Page** section shows the title and content of a page you created in your Shopify admin under **Online Store > Pages**, for example *About us*, *Shipping* or *FAQ*. You write the text in the admin. The section only controls how it looks.

## Where to find it

The section is used on every page template:

* **Default page:** In the theme editor, open the page selector at the top of the screen and choose **Pages > Default page**.
* **Contact** and **Quiz:** Wise also comes with a contact page template and a quiz page template. Both start with the Page section, followed by a contact form or a quiz. Choose them under **Pages** in the same selector.

To use a template for a page, open the page in your Shopify admin and pick the template under **Theme template**.

## Section structure

When you expand the section in the theme editor sidebar, you will see two fixed blocks:

* **Page title:** The title of the page.
* **Page content:** The text, images and other content you entered in the page editor in your Shopify admin. This block has no settings.

## Section settings

* **Compact size:** Limit the width of the title and content to a comfortable reading width (about 850 px). Turn it off to let the content use the full page width set in [Theme settings > Layout](/theme-settings/layout).

#### Colors

* **Background color:** Set the background color of the section.
* **Background gradient:** Set a background gradient. A gradient overrides the background color.
* **Text color:** Set the text color for the whole section.

#### Section spacing

* **Distance top (desktop):** Space above the section on desktop (0 to 100 px).
* **Distance bottom (desktop):** Space below the section on desktop (0 to 100 px).
* **Show custom mobile spacing:** Enable this setting to use different spacing on mobile. When it is on, **Distance top (mobile)** and **Distance bottom (mobile)** appear.

## Page title block

* **Heading scale (desktop):** Make the page title smaller or larger on desktop (50 to 500%).
* **Heading scale (mobile):** Make the page title smaller or larger on mobile (50 to 300%).

:::tip
You can add more sections below the Page section, for example an image with text or a collapsible menu, to build a richer page. Sections added to a template show on every page that uses it, so create a separate template if only one page needs them.
:::
