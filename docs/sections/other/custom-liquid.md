## What is the Custom Liquid section?

<SectionMeta version="v1.0.0" />

The **Custom Liquid** section lets you add your own code to a page as a separate section: an app snippet, an embed code from another service (for example a form, a map or a booking widget), or Shopify Liquid code. Use it when no other section does what you need.

{/* TODO: desktop screenshot or video */}

The section is found under **Other** in the **Add section** menu.

## Section structure

The section has no blocks. Everything it shows comes from the code you enter.

:::tip
To add code inside another section, for example next to a heading or under a product's price, use the [Custom Liquid](/blocks/custom-liquid) block instead.
:::

## Section settings

* **Custom Liquid:** Paste or write your code here. You can use HTML, CSS, JavaScript and [Liquid](https://shopify.dev/docs/api/liquid).

:::note
The section shows your code exactly as it is, with no spacing, colors or width of its own. If you need space around the content or a background, add it in your code. Code that breaks the page layout can affect the sections around it, so preview your page on desktop and mobile after you save.
:::
