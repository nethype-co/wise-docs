## License overview

Every Wise purchase includes a **single-store license**. Each Shopify store that uses Wise needs its own license, bought through the Shopify Theme Store.

This follows [Shopify's Terms of Service](https://www.shopify.com/legal/terms), which require merchants to hold a valid license for every theme they use.

## One license, one store

* Each license covers **one live Shopify store**.
* Using Wise on several stores requires a separate purchase for each store.
* A license is tied to the store it was bought on.

## Several markets in one store

If you sell to **several markets** from one Shopify store (for example, a US market and a European market), you only need **one license**. All markets within the same Shopify store are covered by a single purchase.

If you run separate Shopify stores for different markets, each store needs its own license.

## Development and staging stores

You can install Wise on a **Shopify development store** (password-protected and not taking real payments) without buying a separate license, as long as:

* The theme has been bought on the **live store** it is intended for.
* When you contact support about a development store, you give us the live store's address so we can check the license.

This lets agencies and freelancers build and test client stores before they go live.

## Unlicensed copies

Copies of the theme obtained from anywhere other than the Shopify Theme Store are **not legitimate** and don't get support or updates. If you are using an unlicensed copy, we strongly recommend buying a valid license or removing the theme.

We reserve the right to report unlicensed use to Shopify under their intellectual property policies.

## License transfers

License transfers between stores are handled by **Shopify**. If you need to move your theme license to another store, contact [Shopify Support](https://help.shopify.com/) for help.

:::note
A license transfer usually requires closing the original store. Contact Shopify Support for the current transfer policy.
:::

## Checking your license

To check the status of your theme license, you can:

1. Look in your Shopify admin under **Online Store > Themes**.
2. Contact [Shopify Support](https://help.shopify.com/) to confirm the license.
3. Contact our support team with your store address.
